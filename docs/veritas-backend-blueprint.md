# SAT Prep 教学后台蓝图

## 参考后台的核心闭环

本项目参考 Veritas 教师后台的信息架构，但不复制其界面、代码或私有数据。核心业务闭环是：

1. 学员档案：基本资料、所在班级、学习任务、学习报告、练习情况、课程反馈和考试记录。
2. 班级管理：按科目、班级类型和状态筛选，班级下集中查看作业、课表、反馈、作业大纲、概览和成员。
3. 题库：按考试、分项、来源、名称和关键词筛选，题目或试卷带难度、题量和统计指标。
4. 作业发布：选择题目或试卷，选择班级或学生，设置起止时间、批改老师和发布状态。
5. 作业结果：按科目、状态、班级和日期筛选，显示题目数、平均成绩、完成数和批改数。
6. 结果详情：参与学生、题目、统计和排行榜；学生详情可继续下钻到逐题答案与错题。

## SAT Prep 第一版范围

只做 Patrick 老师当前真正需要的功能：

- 老师和学生账号。
- 学员列表与个人学习档案。
- 班级、班级成员和班级状态。
- SAT 题库与试卷集合。
- 向班级或个别学生发布练习和模考。
- 学生答题、交卷、自动判分。
- 作业完成率、平均分、个人成绩和逐题错题。
- 阅读题按 Module 和题号区分阅读与文法，支持后续自动生成反馈。

暂不实现课表、云盘、申请、金币、实时作业、视频课件、打卡和排行榜，避免第一版过重。

## 数据模型

| 模块 | 主要表 | 作用 |
|---|---|---|
| 账号 | `profiles` | 学生和老师身份、显示名称 |
| 班级 | `classes`, `class_members` | 班级资料及学生成员 |
| 题库 | `question_sets`, `questions` | 试卷集合和稳定题目 ID |
| 作业 | `assignments`, `assignment_classes`, `assignment_recipients`, `assignment_questions` | 发布任务及参与范围 |
| 作答 | `submissions`, `submission_answers` | 交卷、成绩和逐题答案 |
| 统计 | 数据库视图或 RPC | 完成数、平均分、错题率和学生结果 |

`assignment_recipients` 保存发布时的学生快照。即使学生之后退出班级，历史作业和提交记录也不会消失。

## 页面结构

### 老师端

- `/teacher/students`：学生搜索、班级筛选和学生档案。
- `/teacher/classes`：班级列表、成员和班级作业。
- `/teacher/questions`：题库筛选、试卷预览和选题。
- `/teacher/assignments`：作业筛选、创建、发布和结果入口。
- `/teacher/assignments/:id`：参与学生、题目统计和逐题错题。

### 学生端

- `/assignments`：待完成、进行中和已完成作业。
- `/assignments/:id`：作业说明与答题入口。
- `/assignments/:id/result`：成绩、错题和解析。

## 实施顺序

1. 班级和成员表，老师端学生与班级页面。
2. 题库统一稳定 ID，增加试卷集合与筛选字段。
3. 作业发布器，支持班级和个别学生。
4. 学生答题、交卷和服务端自动判分。
5. 作业结果页，完成率、平均分和逐题错题。
6. 基于错题记录生成 Patrick 老师风格的阅读反馈。

## 安全原则

- 学生只能读取自己的作业、提交和答案。
- 老师只能管理自己创建或被授权管理的班级与作业。
- 正确答案、分数和 `is_correct` 不允许学生客户端写入，必须由受控数据库函数计算。
- 前端只使用 Supabase publishable key，不使用 service role key。
- 不从 Veritas 复制学生名单、手机号、成绩或题库内容。
